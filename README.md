# Ailleurs

Booking site for four small themed holiday houses on Réunion Island (Japan, Creole, Morocco, Bali).

Live preview: https://michaelwautier.github.io/ailleurs-site/

```sh
npm install
npm run dev      # http://localhost:4321/ailleurs-site
npm run build
```

Photos: drop images into `public/images/<slug>/` named `01-drone.jpg` … `07-garden.jpg` (see `CLAUDE.md`). They automatically replace the placeholders.

The site copy is in French; code, docs and repository metadata are in English.
