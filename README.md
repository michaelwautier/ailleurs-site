# Ailleurs

Site de réservation pour quatre petites maisons à univers à La Réunion (Japon, créole, Maroc, Bali).

```sh
npm install
npm run dev
```

Photos : déposer les images dans `public/images/<slug>/` avec les noms `01-drone.jpg` … `07-garden.jpg` (voir `CLAUDE.md`). Elles remplacent automatiquement les emplacements vides.
